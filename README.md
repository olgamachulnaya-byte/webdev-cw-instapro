# Instapro

MVP социальной сети для обмена фотографиями.

##Что удалось реализовать

### Базовые требования и приемочные критерии

- Реализован просмотр **общей ленты постов** для авторизованных и неавторизованных пользователей.
- Реализован просмотр **ленты конкретного пользователя** (переход по клику на имя автора).
- Реализованы **регистрация** и **авторизация** с валидацией и отображением ошибок в интерфейсе.
- Реализовано сохранение авторизации в `localStorage` после перезагрузки.
- Реализованы **лайки/дизлайки** только для авторизованных пользователей.
- Реализовано **добавление поста** авторизованным пользователем с проверкой обязательных полей (текст + изображение).

### Интерфейсные «плюшки»

- Плавные анимации появления экранов и карточек (`fade-in`).
- Визуальная обратная связь на лайк:
  - блокировка кнопки на время запроса,
  - мини-анимация (`pulse`) после клика.
- Улучшенная навигация:
  - кнопка «← В общую ленту» на странице ленты пользователя,
  - закрепленный header при скролле.
- Улучшение UX форм:
  - inline-ошибки вместо `alert`,
  - счетчик символов при добавлении поста,
  - состояние загрузки файла с сообщением об ошибке при сбое.
- Адаптивность для мобильных экранов (`@media (max-width: 768px)`).

### Безопасность

- Добавлено экранирование пользовательского текста (имена, описания, заголовки лент), чтобы HTML-теги отображались как текст и не исполнялись (базовая защита от XSS в интерфейсе).
